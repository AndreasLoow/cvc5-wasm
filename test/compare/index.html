cvc5's own cvc5-Wasm.zip, driven through callMain

The artefact this repository replaces: cvc5's command-line binary compiled with emscripten, so every query means writing the script into the virtual filesystem and re-entering main. Loaded from the directory given by ?cli=, measured in the same browser on the same machine as the library build's test page, so the two numbers can be compared.

?mode=trivial times the trivial query; ?mode=corpus runs one pass of bench/swap/. They are separate page loads on purpose: callMain leaks the wasm stack and dies after roughly 137 calls, which is one of the workarounds a library build removes.
